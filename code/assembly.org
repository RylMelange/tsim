|----------+-----------------------------------------------------------------------|
| NOP      | No operation                                                          |
| HLT      | Halt                                                                  |
| CLA      | Clear All: SAR, 'A, 'B                                                |

| SSA      | Store value into SAR'STO from 'A                                      |
